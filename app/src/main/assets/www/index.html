Правила Дзена
    
Проверять возможные риски

    
Это предварительная эвристическая проверка. Она не заменяет модерацию Дзена и не объявляет совпадение нарушением.

    

    

    
Обновление загружается только по кнопке с GitHub-репозитория dzen-text. Встроенная база работает офлайн.

  

  
Словарь синонимов
    
Большой русский словарь уже встроен в приложение и работает без интернета. При желании можно подключить свой JSON/TXT-словарь поверх встроенного. Поддерживается обычная карта «слово → синонимы» и JSON словаря Н. Абрамова с полем wordlist.

    
Встроенный словарь загружается…

    
Свои синонимы: пока нет

    
Мои накопленные синонимы
Пока пусто.

    

    
Замена, введённая вручную в поле «Своя замена», автоматически запоминается для этого слова и в следующий раз показывается первой. Эти пары не удаляются при очистке текста и сохраняются при обновлении приложения.

    
Если найдено слово в другой форме, приложение пытается подобрать начальную форму и сохранить падеж/число у предлагаемой замены. Для сложных словоформ результат лучше проверить глазами.
