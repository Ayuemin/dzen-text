Признаки ИИ-стиля

    
Локальный фильтр проверяет только типографические символы, характерные для машинного текста. Сейчас отмечается длинное тире «—». Словосочетания, клише и смысловые шаблоны здесь не анализируются.

Онлайн-проверка орфографии

    
Онлайн-проверка по умолчанию выключена. Если включить её, текст отправляется в Яндекс.Спеллер только после нажатия кнопки ✓. Автоматический анализ после вставки и загрузки файла остаётся локальным.

Правила Дзена
    
Проверять возможные риски

    
Использовать обновляемую ИИ-базу

    
Это предварительная локальная проверка. Обновляемая база строится на GitHub Actions из официальных правил Дзена с помощью OpenRouter. Текст вашей статьи в OpenRouter не отправляется.

    

    

    
Источник истины — официальная справка Дзена. Приложение получает с GitHub только уже обработанную компактную базу. Функцию можно отключить выше; встроенная база всегда остаётся офлайн.

  

  
Словарь синонимов
    
Большой русский словарь уже встроен в приложение и работает без интернета. При желании можно подключить свой JSON/TXT-словарь поверх встроенного. Поддерживается обычная карта «слово → синонимы» и JSON словаря Н. Абрамова с полем wordlist.

    
Встроенный словарь загружается…

    
Свои синонимы: пока нет

    
Мои накопленные синонимы
Пока пусто.

    

    
Замена, введённая вручную в поле «Своя замена», автоматически запоминается для этого слова и в следующий раз показывается первой. Эти пары не удаляются при очистке текста и сохраняются при обновлении приложения.

    
Если найдено слово в другой форме, приложение пытается подобрать начальную форму и сохранить падеж/число у предлагаемой замены. Для сложных словоформ результат лучше проверить глазами.
