# Локальный ONNX-классификатор

Этот слой полностью опционален. Редактор и все обычные локальные проверки работают без модели.

Чтобы включить смысловой классификатор, добавьте в эту папку два файла:

- `local_text_classifier.onnx`
- `local_text_classifier.json`

JSON должен соответствовать примеру `local_text_classifier.example.json`.

## Контракт модели

Вход — `FLOAT` тензор формы `[N, feature_count]`.

Признаки строятся самим Android-приложением, без внешнего токенизатора:

1. предложение переводится в нижний регистр `ru-RU`;
2. последовательности пробелов схлопываются;
3. добавляются пробелы по краям;
4. строятся символьные n-граммы от `ngram_min` до `ngram_max`;
5. n-граммы раскладываются signed FNV-1a hashing в `feature_count` признаков;
6. вектор L2-нормализуется.

Выход — `FLOAT` тензор `[N, labels]`. Порядок столбцов должен совпадать с порядком `labels` в JSON. Поддерживаются `sigmoid`, `softmax` и `none`.

Модель не получает интернет-доступ и обрабатывает только текст на устройстве. Ошибка или отсутствие модели не должны ломать редактор: в таком случае этот слой просто пропускается.
