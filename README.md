**Дзен Текст** — локальный Android-редактор для подготовки длинных текстов и статей к публикации в Дзен. Статьи, идеи, история версий, словари и редакторские проверки работают на устройстве.

**Следующая версия: v1.11.0 — local-first.**

## Основной принцип

Проверка статьи не зависит от внешнего AI API, Яндекс.Спеллера или облачной базы правил. Приложение не запрашивает Android-разрешение `INTERNET`.

Текст анализируется локально после редактирования с debounce. Кнопка проверки остаётся как ручное принудительное обновление локального анализа.

## Возможности

### Редактор

- редактирование длинных текстов на Android;
- импорт TXT, Markdown и HTML;
- Markdown: заголовки, жирный, курсив, списки, цитаты и ссылки;
- HTML-предпросмотр;
- безопасное копирование для публикации: fallback больше не отправляет сырой Markdown;
- подсчёт слов, знаков и времени чтения;
- системная озвучка Android TTS;
- собственные фоны, шрифты и оформление.

### Статьи и история

Приложение хранит локальную библиотеку статей, идеи и историю версий. Перед опасными действиями создаются защитные снимки. Данные не требуют аккаунта или облака.

### Локальный редакторский анализ

Приложение умеет находить и подсвечивать:

- слишком короткие и длинные заголовки;
- нарушения структуры H1–H3;
- длинные предложения и абзацы;
- большие участки без подзаголовков;
- частые слова;
- повторы в соседних предложениях;
- повторяющиеся фразы;
- одинаковые начала предложений и абзацев;
- ошибки Markdown-разметки;
- пользовательские контрольные слова и фразы;
- механические проблемы пробелов и пунктуации;
- повтор одного слова подряд;
- смешение кириллицы и латиницы;
- типографические сигналы без попыток определять «AI-авторство».

Из замечаний можно переходить к конкретному месту текста и листать совпадения.

### Правила Дзена

Используется встроенный локальный набор эвристик. Он отмечает возможные риски и структурные сигналы, но не выдаёт их за решение модерации Дзена.

Автоматическая AI-генерация и загрузка обновляемой базы отключены. Правила сопровождаются в репозитории как обычные версионируемые данные.

### Синонимы

В APK входит офлайн-словарь русских синонимов. Можно подключить свой JSON/TXT-словарь и сохранять собственные варианты замен.

## Приватность

Версия local-first не запрашивает разрешение Android `INTERNET`. Проверка статьи, правила Дзена, словари, библиотека и история работают локально.

Системный TTS вызывается как служба Android; его собственное поведение зависит от установленного пользователем движка озвучки.

## Установка

Подписанные стабильные APK публикуются в **GitHub Releases**:

**[Скачать последнюю стабильную версию](https://github.com/Ayuemin/dzen-text/releases/latest)**

Начиная с v1.3.3 релизы подписываются постоянным ключом и устанавливаются поверх предыдущих версий. Для local-first линии используется `versionCode 48`, поэтому она сможет обновить установленную v1.10.8 (`versionCode 47`).

## Требования

- Android 7.0+;
- `minSdk 24`;
- `targetSdk 35`.

## Сборка

Нужны Java 17, Android SDK 35 и Gradle 8.10.x.

```bash
gradle :app:assembleDebug
gradle :app:assembleRelease
```

Подписанная release-сборка использует переменные окружения:

- `ANDROID_KEYSTORE_PATH`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_PASSWORD`

Подробно: [docs/BUILD_AND_RELEASE.md](docs/BUILD_AND_RELEASE.md).

## Структура проекта

- `app/src/main/assets/www/` — интерфейс и локальная логика редактора;
- `MainActivity.java` — Android/WebView-мост, файлы, TTS и системные интеграции;
- `DocumentStore.java` — статьи и история версий;
- `rules/` — локальная база правил Дзена;
- `tools/` — regression/invariant проверки;
- `.github/workflows/` — CI и стабильные релизы.

## GitHub Actions

- **Android CI** — проверяет JavaScript и local-first инварианты, затем собирает debug/release APK;
- **Release APK** — собирает подписанный APK и публикует стабильный GitHub Release.
