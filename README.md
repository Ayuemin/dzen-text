**Дзен Текст** — Android-редактор для подготовки длинных текстов и статей к публикации в Яндекс Дзен. Приложение рассчитано на работу прямо со смартфона: текст, статьи, идеи, история версий, словари и большая часть проверок хранятся и работают локально.

**Текущая стабильная версия: v1.9.0.**

## Что изменилось в 1.9.0

Версия 1.9.0 заметно меняет само устройство приложения:

- полноэкранный спокойный редактор вместо перегруженного рабочего экрана;
- боковая панель с действиями текущей статьи и библиотекой;
- несколько локально сохранённых статей вместо одного черновика;
- локальная история версий с защитными снимками перед опасными действиями;
- быстрые **Идеи**, которые можно сохранить отдельно или превратить в статью;
- Markdown-панель над экранной клавиатурой;
- надёжная работа с клавиатурой Android 15 и нижними панелями;
- новые настройки оформления: фон редактора, собственные фоны, шрифты и акцент;
- настройки собраны в понятные тематические разделы;
- усилена защита от потери текста при переключении статей, восстановлении и миграции старых данных.

Полный список изменений находится в [CHANGELOG.md](CHANGELOG.md).

## Основные возможности

### Редактор

- редактирование длинных текстов прямо на Android;
- импорт TXT, Markdown и HTML;
- Markdown: H1–H6, жирный, курсив, списки, цитаты, ссылки, зачёркивание, код и разделители;
- отдельный HTML-предпросмотр;
- копирование форматированного текста для публикации;
- подсчёт слов, знаков и примерного времени чтения;
- системная озвучка Android TTS;
- светлый, тёмный, книжный и пользовательский внешний вид редактора.

### Статьи и история

Приложение хранит статьи внутри своего локального хранилища. В боковой панели можно:

- создать новую статью;
- открыть ранее сохранённую;
- сохранить текущую статью в файл;
- импортировать текст из файла;
- открыть историю версий;
- очистить текущую статью с защитным снимком.

История версий также хранится локально. Общий лимит — **100 МБ**. Старые автоматические снимки могут очищаться автоматически, а пользователь может удалить версии старше недели, старше месяца или всю историю текущей статьи.

### Идеи

Короткую мысль, тему или заголовок можно сохранить отдельно от статьи. Затем идею можно:

- вставить в текущий текст;
- превратить в новую статью;
- удалить.

### Редакторский анализ

Приложение умеет находить и подсвечивать:

- слишком короткие и длинные заголовки;
- нарушения структуры H1–H3;
- длинные предложения и абзацы;
- большие участки без подзаголовков;
- слишком частые слова;
- повторы в соседних предложениях;
- повторяющиеся фразы;
- одинаковые начала предложений и абзацев;
- проблемы Markdown-разметки;
- пользовательские контрольные слова и фразы;
- типичные проблемы пробелов и пунктуации;
- случайные повторы одного слова;
- смешение кириллицы и латиницы внутри одного слова;
- отдельные типографические признаки, которые пользователь хочет контролировать.

Из замечаний можно переходить прямо к нужному месту текста и листать совпадения стрелками.

### Орфография

Есть два режима:

- локальная проверка типичных опечаток, пробелов и пунктуации;
- Яндекс.Спеллер — только если пользователь включил его и сам запустил проверку.

Правильные слова можно добавить в локальные исключения, чтобы больше не получать по ним замечания.

### Повторы и синонимы

В APK входит офлайн-словарь русских синонимов. Также можно:

- подключить собственный JSON/TXT-словарь;
- получать варианты замены повторяющихся слов;
- сохранять собственные варианты синонимов;
- переходить между употреблениями слова;
- заменять выбранное употребление прямо в тексте.

Автоматический подбор грамматической формы остаётся эвристическим, поэтому итоговую фразу лучше проверить глазами.

### Правила Дзена

Отдельная проверка отмечает **возможные** риски по правилам Дзена. Это подсказка редактору, а не автоматический вердикт о нарушении.

Встроенная база работает офлайн. При включённой обновляемой базе приложение получает с GitHub готовый компактный JSON. Workflow репозитория следит за официальной страницей правил; пользовательские статьи в OpenRouter при этом не передаются.

## Приватность

По умолчанию приложение не требует аккаунта, облака или подписки.

Локально на устройстве хранятся:

- статьи;
- история версий;
- идеи;
- настройки;
- пользовательские словари;
- исключения орфографии.

Интернет нужен только для функций, которые явно используют внешний источник:

- обновление базы правил Дзена с GitHub;
- Яндекс.Спеллер, если он включён и пользователь запустил проверку.

## Установка

Готовый подписанный APK публикуется в **GitHub Releases**:

**[Скачать последнюю стабильную версию](https://github.com/Ayuemin/dzen-text/releases/latest)**

Начиная с v1.3.3 релизы подписываются постоянным ключом, поэтому новые версии устанавливаются поверх предыдущих как обычное обновление.

## Требования

- Android 7.0 и новее;
- `minSdk 24`;
- `targetSdk 35`.

## Сборка

Нужны Java 17, Android SDK 35 и Gradle 8.10.x.

```bash
gradle :app:assembleDebug
gradle :app:assembleRelease
```

Подписанная release-сборка использует переменные окружения:

- `ANDROID_KEYSTORE_PATH`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_PASSWORD`

Подробно: [docs/BUILD_AND_RELEASE.md](docs/BUILD_AND_RELEASE.md).

## Структура проекта

- `app/src/main/assets/www/` — интерфейс и логика редактора;
- `MainActivity.java` — Android/WebView-мост, файлы, TTS, системные интеграции;
- `DocumentStore.java` — статьи и история версий;
- `rules/` — локальная база правил Дзена;
- `tools/` — проверки инвариантов и служебные скрипты;
- `.github/workflows/` — CI, стабильные релизы и обновление базы правил.

## GitHub Actions

- **Android CI** — проверяет JavaScript-инварианты и собирает debug/release APK;
- **Release APK** — собирает подписанный APK и публикует стабильный GitHub Release;
- **Update Dzen rules database** — проверяет официальный источник правил и обновляет локальную базу только при необходимости.
