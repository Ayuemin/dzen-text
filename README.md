# Дзен Текст

**Дзен Текст** — автономное Android-приложение для подготовки статей к публикации в Яндекс Дзен. Оно совмещает редактор, HTML-превью, редакторский анализ, поиск повторов, локальный словарь синонимов, проверку текста и озвучку.

Текущая версия: **v1.5.2**.

## Основные возможности

### Редактор и публикация

- редактирование текста прямо на телефоне;
- вставка текста из буфера обмена;
- импорт из TXT, Markdown и HTML-файлов;
- Markdown-подобная разметка: заголовки, жирный текст, списки, цитаты, ссылки и другое;
- HTML-превью статьи;
- копирование форматированного HTML для вставки в редактор Дзена;
- очистка поля одной кнопкой;
- автосохранение черновика;
- панели замены, повторов и исправлений автоматически поднимаются над экранной клавиатурой;
- при переходе к ошибке или совпадению редактор автоматически прокручивает выделенный фрагмент в свободную видимую область над панелью;
- подсчёт знаков, слов и примерного времени чтения.

### Редакторский анализ

В нижней панели постоянно остаётся только компактный индикатор состояния. Если замечаний нет — он зелёный, если есть повод проверить текст — красный. Полный список открывается по нажатию.

Приложение умеет находить:

- слишком короткие и длинные заголовки;
- нарушения структуры H1–H3;
- длинные предложения;
- длинные абзацы;
- большие участки текста без подзаголовков;
- слишком частые слова;
- повторы слов в соседних предложениях;
- повторяющиеся фразы;
- одинаковые начала предложений и абзацев;
- ошибки Markdown-разметки;
- настраиваемые контрольные слова и фразы;
- возможные проблемы с пробелами и пунктуацией;
- случайные повторы одного слова подряд;
- смешение кириллицы и латиницы внутри одного слова.

Из каждого замечания можно перейти прямо к нужному месту текста. Для повторов рядом, повторяющихся фраз и одинаковых начал доступна навигация по совпадениям со счётчиком и стрелками.

### Полная проверка текста

Внизу есть отдельная кнопка **проверки без текстовой подписи**. По нажатию она запускает все включённые проверки сразу.

Поведение зависит от способа ввода:

- если текст вставлен из буфера обмена или загружен из файла, локальный анализ выполняется автоматически и индикатор обновляется сразу;
- если текст набирается вручную, полную проверку можно запустить кнопкой, чтобы приложение не пересчитывало тяжёлый анализ после каждой введённой буквы.

### Орфография

Есть два уровня проверки:

- **локальная проверка** типичных опечаток, пробелов и пунктуации — работает без интернета;
- **онлайн-проверка орфографии через Яндекс.Спеллер** — включается отдельно в настройках и по умолчанию выключена.

Онлайн-проверка выполняется только после явного нажатия кнопки проверки. При выключенной настройке текст во внешний сервис не отправляется. Для найденных орфографических ошибок показываются варианты исправления с возможностью заменить слово прямо из приложения.

### Правила Дзена

Отдельный раздел анализа проверяет текст на **возможные риски по правилам Дзена**. Это эвристическая проверка, а не утверждение о нарушении: итог всегда зависит от контекста и модерации площадки.

Среди проверок:

- возможный кликбейт в заголовке;
- чрезмерное использование заглавных букв и знаков `!` / `?`;
- некоторые опасные или незаконные формулировки;
- категоричные медицинские утверждения;
- возможная ненормативная лексика;
- чрезмерное количество или повторение ссылок.

База правил встроена в приложение и работает офлайн. Её можно вручную обновить из репозитория без установки новой APK.

### Контроль слов

Есть отдельный настраиваемый список контрольных слов и фраз. Например, можно добавить:

```text
VPN
ВПН
обход
обход блокировок
```

Это пользовательский редакторский список, а не официальный перечень запрещённых слов. При обнаружении совпадения приложение показывает его в анализе и позволяет перейти прямо к соответствующему месту текста.

### Повторы и синонимы

- встроенный офлайн-словарь русских синонимов;
- импорт собственного JSON/TXT-словаря;
- предложения замены для часто повторяющихся слов;
- переход между всеми употреблениями слова;
- замена выбранного употребления одним нажатием;
- попытка сохранить подходящую грамматическую форму;
- ручной ввод собственной замены;
- **накопитель собственных синонимов**: введённые вручную варианты запоминаются и в дальнейшем показываются первыми;
- накопленные пары можно просмотреть и очистить в настройках.

Для русского языка автоматическое склонение остаётся эвристическим, поэтому итоговую фразу лучше проверить глазами.

### Озвучка

Приложение использует системный Android Text-to-Speech:

- читает очищенный текст без Markdown-символов и HTML-тегов;
- поддерживает длинные статьи, автоматически разбивая их на части;
- позволяет настроить скорость озвучки;
- работает через установленный в Android голосовой движок.

### Настройки

Можно настроить:

- шрифт;
- размер текста;
- межстрочный интервал;
- светлую, тёмную или системную тему;
- скорость чтения для расчёта времени;
- скорость TTS;
- автосохранение;
- отображение HTML-кода в превью;
- отдельные виды редакторских проверок и их пороги;
- проверку рисков по правилам Дзена;
- онлайн-проверку орфографии;
- контрольные слова;
- внешний и накопленный словарь синонимов.

## Приватность и работа без интернета

Большая часть приложения работает полностью офлайн: редактор, HTML-превью, статистика, редакторский анализ, контроль слов, встроенный словарь синонимов и TTS.

Интернет используется только для функций, которые пользователь запускает отдельно:

- обновление базы правил Дзена с GitHub;
- онлайн-проверка орфографии через Яндекс.Спеллер, если она включена в настройках и пользователь нажал кнопку проверки.

## Установка

Готовые APK публикуются в разделе **Releases**:

https://github.com/Ayuemin/dzen-text/releases

Начиная с версии с постоянной подписью новые APK устанавливаются поверх предыдущих как обычные обновления.

## Требования

- Android 7.0+ (`minSdk 24`)
- целевая версия Android API 35

## Сборка

Проект использует Android Gradle Plugin 8.7.3 и Java 17.

```bash
gradle :app:assembleDebug
```

Release-сборка без ключа подписи создаётся командой:

```bash
gradle :app:assembleRelease
```

Для подписанной release-сборки задайте переменные окружения:

- `ANDROID_KEYSTORE_PATH`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_PASSWORD`

Подробности: [docs/BUILD_AND_RELEASE.md](docs/BUILD_AND_RELEASE.md).

## GitHub Actions

- `Android CI` — проверяет сборку при изменениях в `main` и pull request;
- `Release APK` — при публикации тега `v*` собирает подписанный APK и создаёт GitHub Release.

Ключ подписи хранится в GitHub Secrets и не должен добавляться в репозиторий.

## Словарь синонимов

В APK входит офлайн-словарь на основе проекта `egorkaru/synonym_dictionary`, использующего словарь русских синонимов Н. Абрамова. Информация о сторонних компонентах и лицензии находится в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) и папке [licenses](licenses/).
