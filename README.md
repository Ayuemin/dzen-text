# Дзен Текст

**Дзен Текст** — автономное Android-приложение для подготовки статей к публикации в Яндекс Дзен и других редакторах, которые принимают форматированный HTML.


## Возможности

- редактирование текста на телефоне;
- Markdown-подобная разметка и HTML-превью;
- копирование форматированного HTML для вставки в редактор Дзена;
- подсчёт знаков, слов и примерного времени чтения;
- редакторский анализ с компактным индикатором состояния;
- поиск длинных предложений и абзацев;
- контроль частых повторов и повторов в соседних предложениях;
- анализ структуры и участков без подзаголовков;
- настраиваемый контроль слов и фраз;
- переход из замечания прямо к нужному месту текста;
- офлайн-словарь русских синонимов и ручная замена повторов;
- импорт пользовательского JSON/TXT-словаря синонимов;
- импорт текстов из файлов;
- очистка редактора;
- системная Android Text-to-Speech озвучка очищенного текста без символов разметки;
- светлая и тёмная темы, настройки шрифта и чтения.

## Требования

- Android 7.0+ (`minSdk 24`)
- целевая версия Android API 35

## Сборка

Проект использует Android Gradle Plugin 8.7.3 и Java 17.

```bash
gradle :app:assembleDebug
```

Release-сборка без ключа подписи создаётся командой:

```bash
gradle :app:assembleRelease
```

Для подписанной release-сборки задайте переменные окружения:

- `ANDROID_KEYSTORE_PATH`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_PASSWORD`

Подробности: [docs/BUILD_AND_RELEASE.md](docs/BUILD_AND_RELEASE.md).

## GitHub Actions

- `Android CI` — проверяет сборку при изменениях в `main` и pull request.
- `Release APK` — при публикации тега `v*` собирает подписанный APK и создаёт GitHub Release. Для него нужно один раз добавить секреты подписи в настройках репозитория.

## Словарь синонимов

В APK входит компактный офлайн-словарь на основе проекта `egorkaru/synonym_dictionary`, использующего словарь русских синонимов Н. Абрамова. Информация о сторонних компонентах и лицензии находится в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) и папке [licenses](licenses/).
