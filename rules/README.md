# Editorial Rule Pack v1

Приложение не содержит встроенных правил площадок. Пользователь загружает локальный JSON-пакет формата `editorial-rule-pack-v1`.

Поддерживаемые типы: `word`, `phrase`, `phrase_any`, `phrase_all`, `stem`, `context`, `title_length`, `link_count`, `caps_ratio`, `manual`. Произвольный JavaScript и регулярные выражения не исполняются.

Готовый пример: `editorial-rule-pack-example.json`.
