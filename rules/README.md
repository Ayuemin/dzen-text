# База правил Дзена

`dzen-rules.json` — компактный набор локальных эвристик для проверки статьи на устройстве.

## Принцип работы

Статья пользователя не отправляется во внешние сервисы. Проверка выполняется локально в Android-приложении по встроенным правилам и механическим сигналам.

Источник истины для ручного сопровождения правил — официальная справка Дзена:

`https://dzen.ru/help/ru/requirements/rules.html`

Автоматическая AI-генерация базы отключена. Изменения в `dzen-rules.json` должны проходить обычный review в репозитории: правило должно быть понятным, воспроизводимым и по возможности проверяемым локально без смысловых догадок.

## Что подходит для локальной проверки

- точные слова и фразы;
- основы слов с контекстными ограничениями;
- сочетания темы со словами действия;
- заголовки, CAPS и повторяющиеся знаки;
- количество и повторяемость ссылок;
- другие детерминированные структурные сигналы.

Если правило требует внешних фактов, сравнения с другими публикациями или полноценного понимания смысла, приложение не должно выдавать его как установленное нарушение. Такое правило остаётся ручной рекомендацией.

## Приватность

Проверка статьи работает локально. Ветка local-first не использует OpenRouter для проверки текста и не запускает AI-обновление базы правил.

## Ограничения

Локальная эвристика не предсказывает решение модерации Дзена. Срабатывание означает «проверьте этот фрагмент», а не подтверждение нарушения.
