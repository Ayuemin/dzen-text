# Editorial Rule Pack v1

Приложение не содержит встроенных правил площадок. Пользователь загружает локальный JSON-пакет формата `editorial-rule-pack-v1`.

Поддерживаемые типы: `word`, `phrase`, `phrase_any`, `phrase_all`, `stem`, `context`, `title_length`, `link_count`, `caps_ratio`, `manual`. Произвольный JavaScript, `eval`, функции, регулярные выражения из JSON и сетевые запросы не исполняются.

Поддерживаемые области проверки (`scope`): `title`, `body`, `all`. Заголовок статьи — первый Markdown H1 (`# ...`), а если H1 нет — первая непустая строка исходного текста. `body` — исходный документ без заголовочной строки; позиции замечаний всегда относятся к исходному тексту редактора.

Поиск регистронезависимый. Буквы `е` и `ё` в версии v1 считаются разными символами, чтобы нормализация не меняла индексы `start/end` в исходном тексте.

`manual` не создаёт автоматических замечаний и показывается отдельно как ручной чек-лист.

Готовый самопроверяемый пример: `editorial-rule-pack-example.json`. Поле `test_text` в нём информационное: движок не использует его при обычной проверке, оно предназначено только для ручного теста пакета.
