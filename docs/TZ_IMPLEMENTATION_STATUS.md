# ТЗ 1.0 — матрица реализации

Рабочая ветка для полного ТЗ: `prototype/editorial-rule-packs-full-tz`.

Последняя подтверждённая точка: `93e36529e97eb978ed371707e9be7ab942bc65b1`, Android CI №647 — `success`. В этом CI прошли отдельные regression-тесты `GRAM04/A06`, `STRUCT01-04` и `PACK02-05`, а также debug/release сборка и оба spelling probe APK.

Статусы: `DONE-CI` — автоматизировано и проходит CI, но может требовать телефонной приёмки; `IN PROGRESS` — реализуется; `TODO` — ещё не реализовано; `DEVICE` — обязательно проверить на физическом Android; `QUALITY` — требуется корпус и пороги качества.

## P0

- DOC 01 — `DONE-CI`: постоянный documentId, возрастающая revision, snapshot с textHash/settingsVersion/rulesVersion, отбрасывание старых результатов.
- DOC 02 — `DONE-CI`: единый контракт замечания и UTF-16 диапазоны; автоматические проверки emoji/CRLF/ё.
- DOC 03 — `DONE-CI`: stale-состояние и повторная проверка ревизии/фрагмента перед заменой.
- DOC 04 — `DONE-CI`: транзакционные диапазоны, применение справа налево, одна Undo-точка.
- STYLE 01 — `DONE-CI`: русские повторы без ASCII `\b`.
- DATA 01 — `DONE-CI`: атомарное файловое сохранение и защитные версии для опасных действий; ревизии вынесены в sidecar.
- DATA 02 — `DONE-CI / DEVICE`: восстановление файлов и sidecar автоматизировано; пересоздание Activity, обновление APK и аварийное завершение нужно подтвердить на телефоне.
- PUB 01 — `DONE-CI`: единая модель заголовка и действия «заголовок / текст / всё».
- PUB 02 — `DEVICE`: ClipboardManager и фактическая вставка в два приёмника.

CI подтверждает сборку, наличие словарных ресурсов и Hunspell ABI `arm64-v8a/armeabi-v7a/x86_64`. Нужны одинаковые замеры на физическом телефоне перед выбором и интеграцией.
