# SPELL 01 — эксперимент локальной русской орфографии

Статус: выполняется. Это документ эксперимента, а не утверждение о готовности орфографии.

## Общий протокол

Оба кандидата проверяются отдельно от основного редактора. APK не имеют `INTERNET` permission. Для обоих используется одинаковый набор базовых корректных/ошибочных слов и одинаковый on-device benchmark. На телефоне фиксируются модель устройства, Android API, ABI, размер APK, время холодной и повторной загрузки, приблизительная дополнительная Java-память, число принятых корректных слов, число найденных ошибок, первые пять подсказок и скорость словарных проверок.

После выбора движка отдельный полный корпус SPELL acceptance остаётся обязательным: 300 минимальных примеров + 50 размеченных фрагментов, split 80/20 и пороги из ТЗ. Малый probe-набор не заменяет этот корпус.

## Кандидат A — Morfologik/FSA

- Модуль: `spellprobe-morfologik`.
- Движок: `org.carrot2:morfologik-speller:2.2.0`.
- Русский словарь берётся как ресурс из `org.languagetool:language-ru:6.8`, зависимости LanguageTool runtime не подтягиваются (`transitive = false`).
- LanguageTool Russian speller использует ресурс `ru/hunspell/ru_RU.dict`; исходный README словаря указывает конвертацию из AOT и лицензию LGPL.
- Morfologik распространяется по permissive BSD-style license (см. upstream `LICENSE.txt`).
- CI №616 собрал отдельный Android debug APK успешно. Это подтверждает сборку, но не подтверждает runtime-загрузку ресурсов на конкретном телефоне.

## Кандидат B — Hunspell/JNI

- Модуль: `spellprobe-hunspell`.
- Движок: Hunspell 1.7.2, upstream commit `2969be996acad84b91ab3875b1816636fe61a40e`.
- Интеграция: собственный JNI/CMake bridge, без стороннего Java wrapper.
- Словарь: LibreOffice `ru_RU.aff` + `ru_RU.dic`, pinned commit `32b006a2c22a4ac7e8ed3f03346f7b3d85a970a4`.
- README русского словаря разрешает распространение и модификацию при сохранении copyright/license notices и маркировке изменённых версий.
- Upstream Hunspell 1.7.2 имеет MPL 1.1 / GPL 2.0 / LGPL 2.1 multi-license в исходном header; для приложения перед интеграцией будет выбран и задокументирован совместимый вариант лицензирования.
- Исходники и словарь скачиваются в CI по фиксированным commit SHA через `tools/prepare_hunspell_probe.sh`; в репозиторий они не копируются как случайный непроверенный snapshot.
- APK собирается для `arm64-v8a`, `armeabi-v7a`, `x86_64`.

## Решение

Пока не принято. Выбор делается после успешной сборки обоих APK и измерений на физическом Android. Основной редактор не получает новый spelling engine до завершения этого сравнения.
