# Дзен Текст v1.10.7

Проверка текста стала предсказуемее: локальный анализ работает автоматически, AI запускается только вручную, а замечания последней AI-проверки сохраняются при обычном редактировании и исчезают по мере исправления текста.

## Что изменилось

### Проверка текста

- **Локальная проверка теперь работает автоматически** после ввода, удаления, вставки и программных замен с debounce и без обращения к AI.
- **AI-проверка запускается только вручную** кнопкой «AI-проверка текста» в боковой панели.
- Нижний цветной индикатор только открывает текущие результаты и больше не является второй точкой запуска проверки.
- Замечания последней AI-проверки сохраняются после обычных правок текста; исправленный фрагмент исчезает из списка, остальные замечания остаются.
- Если текст перед замечанием сдвинулся, AI-находка перепривязывается по точной цитате и соседнему контексту.
- Просмотр или переход к замечанию не удаляет его.
- Неудачный новый AI-запрос не уничтожает ещё актуальные замечания предыдущей успешной проверки.
- AI-сессия сбрасывается при смене статьи, импорте/полной замене текста и восстановлении версии, поэтому результаты не переносятся между документами.

### Интерфейс и настройки

- Удалён старый режим «локальная / AI / обе»: локальная проверка теперь является постоянной базовой функцией.
- Настройки разделены понятнее на «Правила Дзена» и «AI-проверка текста».
- У отдельных замечаний больше нет префиксов «AI» / «Локально»; результаты показываются единым списком.
- Статус AI показывает количество оставшихся замечаний после исправлений.
- Markdown-панель над клавиатурой и её настройка удалены, чтобы она больше не перекрывала нижнюю строку статистики и индикатор. Сам Markdown и история Undo/Redo сохранены.

### Публикация в Дзен

- Исправлен Android clipboard для rich paste: plain text и HTML теперь записываются в правильном порядке.
- Успех копирования подтверждается только после фактической попытки записи в системный буфер; при ошибке используется fallback.
- Сохранена подготовка текста для Дзена: заголовок и тело, жирный, курсив, списки, цитаты, ссылки, абзацы и plain-text представление.

### Надёжность

- Добавлены постоянные regression-проверки для нового сценария AI, публикационного clipboard и запрета возврата удалённых режимов/Markdown-панели.
- Финальная проверка перед релизом: AI flow 33/33, publish export 40/40, publish copy 38/38, debug/release сборки успешны.

## После обновления

- Установка выполняется поверх предыдущей версии; статьи, история и настройки сохраняются.
- Сохранённый API-ключ AI-проверки остаётся в защищённом хранилище приложения.
