# Дзен Текст v1.10.8

Большое обновление проверки текста: механические замечания остаются локальными, смысловые задачи переданы AI, а найденные проблемы теперь можно исправлять точечно с помощью модели прямо из окна анализа.

## Что изменилось

### Проверка текста

- Локальные детерминированные проверки продолжают работать автоматически: повторы, частотность, соседние повторы, одинаковые начала, длина предложений и абзацев, структура заголовков, Markdown и другие формализуемые сигналы.
- Яндекс.Спеллер исключён из активного сценария проверки, чтобы убрать ложные орфографические срабатывания на современные слова, заголовки и Markdown.
- AI-проверка отвечает только за задачи, где нужен контекст: орфография спорных слов, грамматика, сложная пунктуация, неудачные формулировки, логика, уместность лексики и смысловые правила Дзена.
- Повторная AI-проверка всегда запускается новым независимым запросом без памяти о предыдущих исправлениях.

### Окно замечаний

- Убраны старые вкладки «Только проблемы / Всё / Правила Дзена».
- Верхний блок теперь состоит из трёх независимых частей: количество локальных замечаний, состояние AI-проверки и действие «Исправить текст с помощью AI».
- Во время AI-проверки показывается честный неопределённый индикатор без вымышленных процентов и счётчиков прогресса.
- После завершения отображается количество найденных AI-замечаний.

### AI-исправление

- «Исправить текст с помощью AI» работает даже если AI-проверка ещё не запускалась: в этом случае модель получает текущие локальные замечания.
- Если AI-проверка уже выполнена и её результат актуален, на исправление передаются локальные и AI-замечания вместе — без дополнительного выбора со стороны пользователя.
- Модель получает всю статью только как контекст, а менять имеет право только отмеченные проблемные фрагменты.
- Ответ принимается только как набор точечных patches `quote → replacement`; полный рерайт статьи не используется.
- Перед применением автоматически создаётся защитная версия «До AI-исправления», изменения входят в Undo/Redo.
- Проверяются точность цитат, перекрытия замен, размер правки, Markdown, ссылки, числа и другие защищённые данные.

### База правил Дзена

- База знаний Дзена теперь обновляется только явной командой пользователя и больше не пересобирается скрыто перед проверкой статьи.
- Приложение сохраняет страницы источников, хеши и результаты обхода, а при следующем обновлении повторно обрабатывает только изменившиеся страницы.
- Первый AI-проход извлекает атомарные правила, второй независимый проход ревизует результат и ищет пропуски, дубли и слишком широкие трактовки.
- Каждое официальное правило обязано иметь точный `source_quote`; правило принимается только если цитата действительно присутствует в загруженном источнике.
- Смысловое замечание по Дзену должно ссылаться на конкретный `rule_id` из сохранённой базы.
- В настройках можно открыть базу и увидеть модель сборки, число найденных/обработанных страниц, ошибки обхода, механические и смысловые правила, их ID, источники и подтверждающие цитаты.

### Мои правила и синонимы

- Добавлены «Мои правила»: точные слова/фразы проверяются локально, смысловые требования передаются AI только при ручной проверке.
- Старый отдельный пользовательский сценарий «нежелательных слов» больше не является самостоятельным механизмом проверки.
- Для синонимов добавлен контекстный AI-подбор: модель получает выбранное место и окружающий текст и предлагает варианты в подходящем значении и форме.
- Встроенный и пользовательский офлайн-словари пока сохранены как резервный источник.

### Надёжность

- Усилена привязка AI-замечаний к точным цитатам и контексту после обычного редактирования текста.
- Исправлен порядок миграции настроек: устаревшие флаги больше не могут перезаписать реальные пользовательские настройки значениями по умолчанию во время старта.
- Добавлены новые regression/invariant-проверки для local/AI-разделения, точечных AI-patches, независимой повторной проверки и source-grounded базы Дзена.
- Финальный CI перед релизом: AI review workflow 17/17, publish export 40/40, publish copy 38/38; debug и release APK успешно собираются.

## После обновления

- Установка выполняется поверх предыдущей версии; статьи, история версий, API-ключ и обычные настройки сохраняются.
- Для использования новых смысловых правил Дзена рекомендуется один раз открыть настройки AI и нажать «Обновить базу правил Дзена».
