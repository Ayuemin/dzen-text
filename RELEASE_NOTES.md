# Дзен Текст v1.10.0

Главное изменение версии — необязательная смысловая AI-проверка статьи по актуальным материалам Дзена.

## Что добавлено

- два режима контроля Дзена: **Встроенная локальная** и **AI + встроенная**;
- подключение любого HTTPS OpenAI-совместимого API через URL, API-ключ и имя модели;
- автоматический рекурсивный сбор базы знаний: стартовый URL ведёт на связанные страницы официальной справки Дзена, затем на ссылки с найденных страниц и так далее;
- выделение моделью правил, рекомендаций, требований к качеству, оформлению и распространению;
- проверка статьи по собранной базе с привязкой замечаний к точным фрагментам текста;
- отдельная редактируемая инструкция для поиска шаблонных и неестественных признаков AI-стиля;
- локальное хранение собранной базы знаний, чтобы не разбирать сайт заново при каждой проверке;
- отчёт о покрытии: сколько страниц найдено, обработано и пропущено, со списком URL;
- явное предупреждение о передаче статьи во внешний API перед включением AI-режима.

## Приватность

По умолчанию приложение по-прежнему использует встроенную локальную проверку и не отправляет статью AI-провайдерам.

Если пользователь сам выбирает **AI + встроенная**, то только после нажатия «Проверить» статья и подготовленная база знаний передаются в указанный им API. API-ключ хранится отдельно от обычных настроек WebView.
