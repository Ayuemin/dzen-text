# Дзен Текст v1.10.4

Исправление публикации: текст, который приложение отдаёт редактору Дзена, теперь всегда корректен.

## Что исправлено

- Копирование для публикации больше не может отправить в редактор Дзена исходный Markdown. Раньше при отказе браузерного копирования в буфер попадал сырой текст с `##`, `**` и `[текст](ссылка)`, и Дзен публиковал эти символы как обычный текст статьи.
- Обе версии буфера — HTML и простой текст — строятся из одного и того же отрендеренного материала и больше не могут разойтись.
- Текст копируется через системный буфер обмена с явными HTML и простым текстом. Первый элемент буфера содержит оба формата, поэтому редактор, который читает только его, всё равно получает оформленный текст.
- Заголовок `# ...` больше не дублируется в теле статьи: у Дзена заголовок — отдельное поле, и пользователю не придётся вырезать его вручную.
- Исправлена подстановка кавычек в ссылку: адрес вида `https://..."onmouseover="…` больше не может сломать HTML, который уходит в редактор.
- Ссылка с недопустимым адресом публикуется как её видимый текст, а не как Markdown-разметка.
- Больше не остаётся в буфере полная копия статьи: временный контейнер очищается, а выделение текста возвращается на место.

## Проверки

- Появились первые в проекте поведенческие тесты публикации: они проверяют конвертацию, безопасность HTML и содержимое буфера во всех сценариях копирования. Теперь они выполняются при каждой сборке в CI.

## Установка

Сборка подписана прежним постоянным ключом, поэтому обновление ставится поверх установленной версии обычным способом.
